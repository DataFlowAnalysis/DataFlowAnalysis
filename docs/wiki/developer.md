# Developer Docs
This section provides documentation and setup information for setting up the analysis framework in [Eclipse](/wiki/development/eclipse) and [IntelliJ](/wiki/development/intellij).

Additionally, the [Running Locally Section](/wiki/development/running-locally) show how the analysis framework can be used in Java with our API.

If you want to build on top of the analysis in your own project, see [Extending the Analysis](/wiki/development/extending) for how to depend on it via Maven and how to reference its Ecore models if you need to extend the metamodel itself.

Lastly, the [Style Guide](/wiki/development/style) documents some design and style decisions that were discussed internally.
